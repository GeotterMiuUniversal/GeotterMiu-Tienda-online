Descargar HTML para GitHub Pages

Genera el archivo completo listo para subir a GitHub Pages.
Recomendado: usa Descargar HTML (evita problemas de pegado y límites de tamaño).

Instrucciones para GitHub Pages

  1. Edita los cursos en la pestaña Cursos.
  2. Haz clic en Descargar HTML.
  3. Renombra el archivo descargado a index.html.
  4. Súbelo a la raíz de tu repositorio de GitHub Pages (reemplaza el anterior).
  5. Espera 1-2 minutos y recarga tu sitio.
